# TaskBoard.Web

Angular single-page dashboard for TaskBoard. See the repository [README](../../README.md) for the
full-stack setup.

| Command | Purpose |
|---|---|
| `npm start` | Dev server on http://localhost:4200 (expects the API on http://localhost:5180) |
| `npm run build` | Production build into `dist/` |
| `npm test` | Unit/component tests (Vitest) in watch mode |
| `npm run test:ci` | Unit/component tests once |

The API base URL is configured in `src/environments/environment*.ts`.
